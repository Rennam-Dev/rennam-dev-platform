# Internacionalização

## Idiomas

- `pt-BR` como idioma editorial inicial.
- `en` para páginas institucionais, projetos principais e artigos selecionados.

## URLs

- `/pt-br/...`
- `/en/...`

## Regras

- Traduções são registros independentes ligados à mesma entidade.
- Cada idioma possui título, slug, conteúdo, SEO e status próprios.
- Não criar URL vazia para tradução inexistente.
- O seletor aponta para a página equivalente quando existir.
- `hreflang` é recíproco e gerado apenas para traduções publicadas.
- Canonical aponta para a própria versão localizada.
