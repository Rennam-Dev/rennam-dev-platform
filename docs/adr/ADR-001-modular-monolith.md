# ADR-001: Monólito modular

## Status
Aceito

## Contexto
O site público, CMS, identidade e portal compartilham domínio, banco e ciclo de desenvolvimento.

## Decisão
Usar monólito modular. Labs pesados permanecem separados quando necessário.

## Consequências
Menor complexidade operacional no início, com limites explícitos para extrações futuras.
